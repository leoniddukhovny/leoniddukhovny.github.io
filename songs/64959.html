Перечитывая А.Вознесенского (Ностальгия по настоящему) (стих)

                  Леонид Духовный

Как-то встретились, поговорили,             
Анекдотов раздали по ящику...
Вроде не были,вроде были –
Ностальгия по настоящему
Океанами серыми плыли
За надеждами нашими вящими...
          Вроде не были,вроде были –
         Ностальгия по настоящему


Избегаем душевных усилий,                 
Чувств высоких боясь,- почему ?        
        Они рвутся из нас, они были            
В ностальгии по настоящему.         
          Песни  бардов- летящие крылья...
Галич,Визбор,Высоцкий ,Ященко...
Вроде не были,вроде были...
Ностальгия по настоящему.
"Я не знаю,как остальные,
Но я чувствую жесточайшую
          Не по прошлому ностальгию-
Ностальгию по настоящему."
